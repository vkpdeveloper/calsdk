---
title: The event model
description: The one event shape every provider returns, and what each field means.
---

Every provider returns the same `CalendarEvent`. Here is one read from Outlook:

```ts
{
  id: 'AAMkAGI2TG93AAA=',
  calendarId: 'primary',
  kind: 'single',
  title: 'Design review',
  description: 'Walk through the new onboarding flow.',
  location: 'Room 4',
  start: { dateTime: '2026-11-03T10:00:00+05:30', timeZone: 'Asia/Kolkata' },
  end: { dateTime: '2026-11-03T11:00:00+05:30', timeZone: 'Asia/Kolkata' },
  status: 'confirmed',
  showAs: 'busy',
  organizer: { email: 'ana@example.com', name: 'Ana', self: true },
  attendees: [
    { email: 'raj@example.com', name: 'Raj', responseStatus: 'accepted' },
  ],
  conference: { provider: 'teams', joinUrl: 'https://teams.microsoft.com/l/meetup-join/...' },
  etag: 'W/"DwAAABYAAAA="',
  htmlLink: 'https://outlook.office365.com/owa/?itemid=...',
  createdAt: '2026-10-28T09:12:00Z',
  updatedAt: '2026-10-30T14:03:00Z',
  providerMetadata: { microsoft: { importance: 'normal', showAs: 'busy' } },
}
```

The same meeting from Google has a different id, a Meet link and Google's metadata, and every other field the same.

## Identity

- **`id`** is the provider's id for the event. Pass it to `getEvent`, `updateEvent` and `deleteEvent`, with the same `calendarId`.
- **`calendarId`** is the calendar the event was read from.
- **`kind`** is `single`, `series`, `occurrence` or `exception`. See [Recurring events](/docs/guides/recurring-events).
- **`seriesId`** and **`originalStart`** are set on occurrences and exceptions: the series they belong to, and where its rule placed them.

Ids are strings with no fixed format. Store them as they are.

## When

- **`start`** and **`end`** are either both timed, `{ dateTime, timeZone }`, or both all-day, `{ date }`. All-day end dates are exclusive. See [Time zones](/docs/concepts/time-zones).
- **`recurrence`** holds the RFC 5545 lines of a series, such as `['RRULE:FREQ=WEEKLY;BYDAY=MO', 'EXDATE:20261110T100000Z']`.

## Status and availability

- **`status`** is `confirmed`, `tentative` or `cancelled`. `cancelled` is rare: it is for events that still have their details, such as an Outlook meeting the organizer cancelled. Deleted events are not returned at all, and sync reports them as `delete` changes.
- **`showAs`** is `busy` or `free`, which decides whether the event blocks time in free/busy. Providers with more states, such as Outlook's out of office, put the original in `providerMetadata`.
- **`visibility`** is `default`, `public` or `private`.

## People

- **`organizer`** is a `{ email, name?, self? }`. `self` is `true` when it is the signed-in user.
- **`attendees`** add `responseStatus` (`needsAction`, `accepted`, `declined`, `tentative`), `optional` and `organizer`.

Some providers leave attendees out of listings because reading them costs a request per event. Fetch the event with `getEvent` when you need them. The provider pages say which.

## Extras

- **`conference`** is the video link: `{ provider, joinUrl, id? }`, where `provider` is `google-meet`, `teams`, `zoom` or `other`.
- **`reminders`** is `{ useDefault, overrides? }`, each override a `{ method: 'popup' | 'email', minutesBefore }`.
- **`color`** is a hex color, `'#RRGGBB'`.
- **`htmlLink`** opens the event in the provider's own app.
- **`etag`** is a version tag. Pass it as `ifMatch` to write only if nobody changed the event since.
- **`createdAt`** and **`updatedAt`** are ISO 8601 timestamps.
- **`providerMetadata`** holds fields only one provider has, keyed by provider id. See [Provider options](/docs/guides/provider-options).

Every field except `id`, `calendarId`, `kind`, `start`, `end`, `status` and `showAs` is optional. A provider leaves out what it does not have.

## Writing events

`createEvent` takes an `EventInput`, a smaller shape with only the fields you can set: `title`, `description`, `location`, `start`, `end`, `recurrence`, `showAs`, `visibility`, `attendees`, `createConference`, `reminders` and `color`. `updateEvent` takes the same fields as a partial `EventPatch`, where `null` clears a field. See [Types](/docs/reference/types) for both.
