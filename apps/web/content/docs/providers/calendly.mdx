Calendly is a scheduling tool, so its events are the meetings people have booked with your user. You can list them, sync them, book a new one on an event type and cancel one. Two limits shape everything else: Calendly [can't change a scheduled meeting](https://developer.calendly.com/frequently-asked-questions) at all, and its API books only [a few meetings a day on the free plan](https://developer.calendly.com/api-docs/overview/rate-limits).

```npm
npm install @cal-sdk/core @cal-sdk/calendly
```

```ts
import { createEvent, listEvents } from '@cal-sdk/core';
import { calendly } from '@cal-sdk/calendly';

const calendar = calendly({ accessToken: process.env.CALENDLY_TOKEN! });

const { events } = await listEvents({
  calendar,
  timeMin: '2026-11-01T00:00:00Z',
  timeMax: '2026-12-01T00:00:00Z',
});

// Book a 30 minute event type for a guest.
await createEvent({
  calendar,
  event: {
    start: { dateTime: '2026-11-03T10:00:00', timeZone: 'Europe/Berlin' },
    end: { dateTime: '2026-11-03T10:30:00', timeZone: 'Europe/Berlin' },
    attendees: [{ email: 'guest@example.com', name: 'Guest' }],
  },
  providerOptions: {
    calendly: { eventType: 'https://api.calendly.com/event_types/<uuid>' },
  },
});
```

## Credentials

`accessToken` is a [personal access token](https://developer.calendly.com/docs/authentication/how-to-authenticate-with-personal-access-tokens) or OAuth access token with the [scopes](https://developer.calendly.com/docs/authentication/scopes) `users:read` and `scheduled_events:read`, plus `event_types:read` and `scheduled_events:write` to book.

## What does calsdk not support on Calendly?

Updating, all-day and recurring events, `ifMatch` and search aren't supported. Free/busy is computed from meetings. See the [comparison](/docs/providers) for every provider.

## Calendly behavior

### Calendars, ids and times

`'primary'` holds every meeting the user hosts. Calendly can't [list meetings](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/list-scheduled-events) by event type, so there are no other calendars. An event id is the scheduled event's uuid, and times are shown in the user's Calendly time zone.

### Booking

Creating an event books an event type through Calendly's [Scheduling API](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/create-event-invitee), which allows [5 bookings a day on the free plan](https://developer.calendly.com/api-docs/overview/rate-limits) and 100 a day on paid plans below Enterprise. The meeting lasts as long as the event type, and other lengths throw `InvalidArgumentError`. Calendly only books times the event type has free. The first attendee books the meeting and the others are added as guests (Calendly accepts up to 10). Without attendees, the user books it for themselves. Fields the event type sets (`title`, `description`, `location`, `createConference`, `reminders`, `color`, `visibility`) are ignored with a [warning](/docs/concepts/warnings).

### Can calsdk reschedule a Calendly meeting?

Not in place. The [Calendly API](https://developer.calendly.com/api-docs) can't change a scheduled meeting, so `updateEvent` throws `UnsupportedFunctionalityError`. To reschedule, delete the meeting and book a new one.

[`deleteEvent`](/docs/reference/delete-event) cancels the meeting through Calendly's [cancel endpoint](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/create-scheduled-event-cancellation), and cancelled meetings read as deleted events. Calendly always emails invitees, so `sendUpdates` values other than `'all'` return a warning.

### Listing and sync

Listing finds meetings by their start. Calendly meetings last at most [12 hours](https://developer.calendly.com/api-docs/calendly-api/event-types/create-event-type) (720 minutes), so calsdk looks back a day to catch meetings that started before `timeMin` and end inside the window.

`getEvent` and `createEvent` return the hosts, the invitees and the guests they added. Listing and sync leave `attendees` out, because Calendly needs a [request per meeting](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/list-event-invitees) for its invitees, and a month of meetings would mean a request for each. Hosts are in `organizer`.

Calendly can't [list meetings by when they changed](https://developer.calendly.com/api-docs/calendly-api/scheduled-events/list-scheduled-events), so each [sync](/docs/guides/sync) reads every active meeting and compares it with the last sync. All changes come on one page, and the cursor grows with the number of meetings.

## Provider options

```ts
await createEvent({
  calendar,
  event,
  providerOptions: {
    calendly: { eventType: '<uuid>', location: { kind: 'physical', location: 'Office' } },
  },
});

await deleteEvent({
  calendar,
  eventId,
  providerOptions: { calendly: { reason: 'No longer needed' } },
});
```
