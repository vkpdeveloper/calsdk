title: Compare providers

---

Every provider declares what it supports in `calendar.capabilities`. This table is that data. "Some" means it depends on a condition, given below the table.

| Feature                    | Google | Outlook | CalDAV | Cal.com | Calendly | Zoom | ICS  | Mock |
| -------------------------- | :----: | :-----: | :----: | :-----: | :------: | :--: | :--: | :--: |
| Write events               | Yes    | Yes     | Yes    | Yes     | Yes      | Yes  | No   | Yes  |
| Keeps title and description | Yes   | Yes     | Yes    | No      | No       | Yes  | No   | Yes  |
| All-day events             | Yes    | Yes     | Yes    | No      | No       | No   | Some | Yes  |
| Recurring events           | Yes    | Yes     | Yes    | No      | No       | Some | Some | Yes  |
| This and following         | Yes    | No      | No     | No      | No       | No   | No   | Yes  |
| Attendees                  | Yes    | Yes     | Yes    | Yes     | Yes      | Yes  | Some | Yes  |
| Creates video links        | Yes    | Some    | No     | No      | No       | Yes  | No   | Yes  |
| Reminders                  | Yes    | Some    | No     | No      | No       | No   | No   | Yes  |
| Colors                     | Yes    | No      | No     | No      | No       | No   | No   | Yes  |
| Etags and `ifMatch`        | Yes    | Yes     | Yes    | No      | No       | No   | No   | Yes  |
| Search                     | Yes    | No      | No     | No      | No       | No   | No   | Yes  |
| Free/busy endpoint         | Yes    | No      | No     | No      | No       | No   | No   | No   |
| Sync                       | Yes    | Yes     | Yes    | Yes     | Yes      | Yes  | Yes  | Yes  |

**Conditions**

- **Outlook video links:** Teams meetings need a work or school account.
- **Outlook reminders:** one popup reminder per event.
- **Zoom recurring events:** daily, weekly on set weekdays, or monthly on a day or an nth weekday, for up to 60 meetings or until a date. One meeting of a series can only be moved, resized or deleted.
- **ICS:** feeds are read only. All-day, recurring and attendee data is read but cannot be written.

"Keeps title and description" is about scheduling tools: Cal.com and Calendly name bookings after their event type, so a title you pass is ignored with a warning.

Free/busy works on every provider: where there is no endpoint, calsdk computes it from events and returns a warning. Search does not: providers without it throw `UnsupportedFunctionalityError`.

Webhooks are part of the provider contract, but no provider implements them yet. Use [sync](/docs/guides/sync) on a schedule.

## Check at runtime

```ts
const { events } = calendar.capabilities;

if (events.recurrenceScopeThisAndFollowing === true) {
  await updateEvent({ calendar, eventId, scope: 'thisAndFollowing', patch });
}
```

Values are `true`, `false`, `'unknown'` or `{ condition: string }`. Treat anything but `true` as "check first". See [Capabilities](/docs/reference/capabilities).
