---
title: Capabilities
description: The capability flags every provider declares, and what each one means.
---

Every provider has a `capabilities` object. calsdk uses it to pick fallbacks, the conformance suite runs only the tests a provider declares, and these docs build the [provider comparison](/docs/providers) from it.

```ts
calendar.capabilities.events.recurrenceScopeThisAndFollowing; // true, false, 'unknown' or { condition }
```

## Values

| Value | Meaning |
| --- | --- |
| `true` | Always supported |
| `false` | Never supported |
| `'unknown'` | The provider cannot tell ahead of time. Not the same as unsupported |
| `{ condition: string }` | Supported only under the condition, such as `'Teams meetings need a work or school account.'` |
