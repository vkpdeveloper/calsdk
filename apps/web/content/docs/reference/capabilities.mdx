---
title: Capabilities
metaTitle: "Capabilities: what each calendar provider supports"
description: Capabilities are the flags each calsdk provider declares, such as events.recurrence or freeBusy, to say which calendar features it supports.
---

Check them before you offer a feature, such as "edit this and following" or a video link, so you only show what the user's calendar can do. calsdk also uses them to pick fallbacks, the [conformance suite](/docs/build-a-provider/conformance) runs only the tests a provider declares, and these docs build the [provider comparison](/docs/providers) from them.

```ts
calendar.capabilities.events.recurrenceScopeThisAndFollowing; // true, false, 'unknown' or { condition }
```

## Values

| Value | Meaning |
| --- | --- |
| `true` | Always supported |
| `false` | Never supported |
| `'unknown'` | The provider cannot tell ahead of time. Not the same as unsupported |
| `{ condition: string }` | Supported only under the condition, such as `'Teams meetings need a work or school account.'` |

Outlook's `events.conference` carries that condition: calsdk asks for a `teamsForBusiness` meeting, and Outlook calendars [offer Teams meetings through a Microsoft 365 business or enterprise plan](https://learn.microsoft.com/en-us/graph/outlook-calendar-online-meetings). A [custom provider](/docs/build-a-provider) declares its own flags the same way.
