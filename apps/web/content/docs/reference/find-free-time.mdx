---
title: findFreeTime
description: Finds slots when every listed calendar is free, across providers.
---

Pass everyone's calendars, even on different providers, and set `workingHours` so slots land inside the working day of the person you're booking. Slots come back as UTC instants, ready to show in each viewer's own zone.

```ts
import { findFreeTime } from 'calsdk';

const { slots } = await findFreeTime({
  calendars: [{ calendar: google({ accessToken }) }, { calendar: microsoft({ accessToken }) }],
  timeMin: new Date(),
  timeMax: new Date(Date.now() + 7 * 86_400_000),
  duration: 30,
  workingHours: { start: '09:00', end: '18:00', timeZone: 'Asia/Kolkata' },
});
```

## Result

<TypeTable
  type={{
    slots: { type: '{ start: string; end: string }[]', description: 'Free slots in order, as UTC ISO 8601 instants. Neighbouring slots overlap when slotInterval is less than duration.', required: true },

/>

## Throws

- `FreeBusyUnavailableError` when any calendar cannot be read, rather than return slots that might clash. It has `provider` and `calendarId`.
- `InvalidArgumentError` when `duration` or `slotInterval` is not a positive whole number, or `workingHours` is invalid.
