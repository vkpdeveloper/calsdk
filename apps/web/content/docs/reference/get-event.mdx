---
title: getEvent
metaTitle: "getEvent: fetch one calendar event by id"
description: getEvent fetches one calendar event by id from any calsdk provider, with its current details and attendees.
---

Use `getEvent` when you have an event's id and want its current details, including attendees that some providers [leave out of listings](/docs/concepts/events#people). To read many events at once, use [`listEvents`](/docs/reference/list-events) instead.

```ts
import { getEvent } from '@cal-sdk/core';

const { event } = await getEvent({ calendar, eventId });
```

## Options

<TypeTable
  type={{
    eventId: { type: 'string', description: 'A single event, series, occurrence or exception id.', required: true },
    calendarId: { type: 'string', default: "'primary'" },
  }}
/>

Plus the [common options](/docs/reference#common-options).

## Result

<TypeTable
  type={{
    event: { type: 'CalendarEvent', description: 'The event. `providerMetadata` is typed by the provider.', required: true },
    warnings: { type: 'Warning[]', required: true },
  }}
/>

See [`CalendarEvent`](/docs/reference/types#calendarevent) for every field of the event.

## Throws

- `NotFoundError` when the event or calendar does not exist or is not visible to the user. `resource` says which. [Errors](/docs/reference/errors) lists its other fields.
