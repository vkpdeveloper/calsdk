---
title: getEvent
description: Fetches one event by id.
---

Use `getEvent` when you have an event's id and want its current details, including attendees that some providers leave out of listings.

```ts
import { getEvent } from '@cal-sdk/core';

const { event } = await getEvent({ calendar, eventId });
```

## Options

<TypeTable
  type={{
    eventId: { type: 'string', description: 'A single event, series, occurrence or exception id.', required: true },
    calendarId: { type: 'string', default: "'primary'" },
  }}
/>

Plus the [common options](/docs/reference#common-options).

## Result

<TypeTable
  type={{
    event: { type: 'CalendarEvent', description: 'The event. `providerMetadata` is typed by the provider.', required: true },
    warnings: { type: 'Warning[]', required: true },
  }}
/>

## Throws

- `NotFoundError` when the event or calendar does not exist or is not visible to the user. `resource` says which.
