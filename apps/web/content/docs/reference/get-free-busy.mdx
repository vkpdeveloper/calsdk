---
title: getFreeBusy
metaTitle: "getFreeBusy: busy times for one or more calendars"
description: getFreeBusy returns merged busy blocks for one or more calendars on one provider, without exposing what the events are.
---

Use `getFreeBusy` when you need to know when someone is busy, not what their events are. To find open slots across several providers at once, use [`findFreeTime`](/docs/reference/find-free-time).

```ts
import { getFreeBusy } from '@cal-sdk/core';

const { calendars } = await getFreeBusy({
  calendar,
  calendarIds: ['primary', 'team@example.com'],
  timeMin: new Date(),
  timeMax: new Date(Date.now() + 7 * 86_400_000),
});
```

Google answers from its [free/busy endpoint](https://developers.google.com/workspace/calendar/api/v3/reference/freebusy/query). Other providers are read from their events instead, with a `compatibility` warning: [Find free time](/docs/guides/free-time) covers how the busy times are worked out.

## Result

<TypeTable
  type={{
    calendars: { type: 'Record<string, { busy: BusyBlock[]; error?: string }>', description: 'Keyed by requested calendar id. busy is merged, sorted and clipped to the window. error is set when that calendar could not be read.', required: true },
    warnings: { type: 'Warning[]', required: true },
  }}
/>

A `BusyBlock` is `{ start: string; end: string }`, ISO 8601 instants with `end` exclusive.
