---
title: getFreeBusy
description: Returns busy blocks for one or more calendars of one provider.
---

Use `getFreeBusy` to see when someone is busy without reading what their events are. Only Google has a free/busy endpoint; for other providers calsdk reads the events and works out the busy times, with a warning.

```ts
import { getFreeBusy } from 'calsdk';

const { calendars } = await getFreeBusy({
  calendar,
  calendarIds: ['primary', 'team@example.com'],
  timeMin: new Date(),
  timeMax: new Date(Date.now() + 7 * 86_400_000),
});
```

Providers with a free/busy endpoint (Google) use it. Others list events instead, skipping events shown as free and cancelled events, and return a `compatibility` warning.

## Result

<TypeTable
  type={{
    calendars: { type: 'Record<string, { busy: BusyBlock[]; error?: string }>', description: 'Keyed by requested calendar id. busy is merged, sorted and clipped to the window. error is set when that calendar could not be read.', required: true },
    warnings: { type: 'Warning[]', required: true },
  }}
/>

A `BusyBlock` is `{ start: string; end: string }`, ISO 8601 instants with `end` exclusive.
