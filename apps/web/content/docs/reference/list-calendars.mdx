---
title: listCalendars
metaTitle: "listCalendars: list the calendars a user can see"
description: listCalendars lists every calendar the signed-in user can see on a provider, such as work, personal and shared team calendars.
---

Show the list so users can pick which calendar you read and write, then pass the chosen `id` as `calendarId` to functions such as [`listEvents`](/docs/reference/list-events). Leave `calendarId` out and they use the user's primary calendar.

```ts
import { listCalendars } from '@cal-sdk/core';

const { calendars } = await listCalendars({ calendar });
```

## Options

Only the [common options](/docs/reference#common-options).

## Result

<TypeTable
  type={{
    calendars: { type: 'Calendar[]', description: 'Every calendar the user can see. Exactly one has `isPrimary: true`.', required: true },
    warnings: { type: 'Warning[]', required: true },
  }}
/>

See [`Calendar`](/docs/reference/types#calendar) for the fields of each calendar, and [Calendars](/docs/guides/calendars) for what `'primary'` means on each provider.

## Throws

- `AuthenticationError` when the credentials are rejected.
