Import types from `calsdk`:

```ts
import type { Calendar, CalendarEvent, EventInput, EventPatch, EventTime } from 'calsdk';
```

The event type is named `CalendarEvent` so it does not clash with the DOM's `Event`.

## EventTime

Either timed or all-day, never both. `start` and `end` of one event use the same form.

<TypeTable
  type={{
    dateTime: { type: 'string', description: "Timed. ISO 8601 with an offset, such as '2026-11-03T10:00:00+05:30'. On input, the offset may be left out." },
    timeZone: { type: 'string', description: "Timed. The IANA zone the event was scheduled in, such as 'Asia/Kolkata'." },
    date: { type: 'string', description: "All-day. 'YYYY-MM-DD'. Exclusive on end." },
  }}
/>

## EventInput

What `createEvent` takes. `EventPatch`, for `updateEvent`, has the same fields, all optional, and `null` clears a field other than `start` and `end`.

## People

<TypeTable
  type={{
    email: { type: 'string', required: true },
    name: { type: 'string' },
    self: { type: 'boolean', description: 'true when this person is the signed-in user.' },
    responseStatus: { type: "'needsAction' | 'accepted' | 'declined' | 'tentative'", description: 'Attendee only.' },

    organizer: { type: 'boolean', description: 'Attendee only.' },
  }}
/>

`Person` has `email`, `name` and `self`. `Attendee` adds the rest, with `responseStatus` required.

## Other types

| Type | Shape |
| --- | --- |
| `BusyBlock` | `{ start: string; end: string }`, ISO 8601 instants, `end` exclusive |
| `SyncChange` | `{ type: 'upsert'; event: CalendarEvent } \| { type: 'delete'; eventId: string }` |
| `UpdateScope` | `'this' \| 'all' \| 'thisAndFollowing'` |
| `SendUpdates` | `'all' \| 'externalOnly' \| 'none'` |
| `CalendarProvider` | Any provider instance. See [Build a provider](/docs/build-a-provider) |
| `CalendarCapabilities` | See [Capabilities](/docs/reference/capabilities) |
| `EventOf<C>` | `CalendarEvent` with `providerMetadata` typed by provider `C` |
| `ProviderOptionsFor<C, Operation>` | The `providerOptions` provider `C` accepts for an operation |
