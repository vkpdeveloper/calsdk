title: Types

These are the shapes every function takes and returns, the same for every provider. Import them from `@cal-sdk/core`:

```ts
import type { Calendar, CalendarEvent, EventInput, EventPatch, EventTime } from '@cal-sdk/core';
```

The event type is named `CalendarEvent` so it doesn't clash with the DOM's `Event`.

## EventTime

Either timed or all-day, never both. `start` and `end` of one event use the same form.

A timed event has both fields:

<TypeTable
  type={{
    dateTime: { type: 'string', description: "ISO 8601 with an offset, such as `'2026-11-03T10:00:00+05:30'`. On input, the offset may be left out.", required: true },
    timeZone: { type: 'string', description: "The IANA zone the event was scheduled in, such as `'Asia/Kolkata'`.", required: true },
  }}
/>

An all-day event has only a date:

<TypeTable
  type={{
    date: { type: 'string', description: "`'YYYY-MM-DD'`. Exclusive on `end`: a one-day event on the 3rd ends on the 4th.", required: true },
  }}
/>

## EventInput

What `createEvent` takes. `EventPatch`, for `updateEvent`, has the same fields, all optional, and `null` clears a field other than `start` and `end`.

  }}

## Other types

| Type | Shape |
| --- | --- |
| `BusyBlock` | `{ start: string; end: string }`, ISO 8601 instants, `end` exclusive |
| `SyncChange` | `{ type: 'upsert'; event: CalendarEvent } \| { type: 'delete'; eventId: string }` |
| `UpdateScope` | `'this' \| 'all' \| 'thisAndFollowing'` |
| `SendUpdates` | `'all' \| 'externalOnly' \| 'none'` |
| `CalendarProvider` | Any provider instance. See [Build a provider](/docs/build-a-provider) |
| `CalendarCapabilities` | See [Capabilities](/docs/reference/capabilities) |
| `EventOf<C>` | `CalendarEvent` with `providerMetadata` typed by provider `C` |
| `ProviderOptionsFor<C, Operation>` | The `providerOptions` provider `C` accepts for an operation |
| `ProviderMetadata` | `Record<string, JSONObject>`: one plain JSON object per provider id |
